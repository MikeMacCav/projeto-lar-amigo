# \# 🐾 Lar Amigo - Site Oficial da ONG

# 

# Este repositório contém o código-fonte do site oficial da \*\*Lar Amigo\*\*, uma organização sem fins lucrativos fictícia focada no resgate, cuidado, reabilitação e promoção da adoção responsável de cães e gatos abandonados ou vítimas de maus-tratos.

# 

# O projeto foi desenvolvido como parte da \*\*ATPS (Atividade Teórico-Prática Supervisionada)\*\* para a disciplina de \*\*Design para WEB\*\* do curso de Engenharia de Software (1º Semestre de 2025).

# 

# \---

# 

# \## 🚀 Tecnologias Utilizadas

# 

# Para a construção deste ecossistema web puramente informativo e focado na usabilidade, foram utilizadas tecnologias nativas de desenvolvimento web:

# 

# \- \*\*HTML5:\*\* Estruturação semântica e acessível do conteúdo.

# \- \*\*CSS3:\*\* Estilização visual completa, sem o uso de frameworks externos (Bootstrap/Tailwind).

# &#x20; - \*\*CSS Grid Layout:\*\* Utilizado na diagramação e alinhamento dos cartões da galeria de animais.

# &#x20; - \*\*Flexbox:\*\* Utilizado na distribuição simétrica dos elementos de cabeçalho, rodapé e seções de contato.

# &#x20; - \*\*Media Queries:\*\* Implementadas para assegurar a responsividade mínima do layout em dispositivos móveis (smartphones e tablets).

# 

# \---

# 

# \## 📂 Estrutura de Páginas do Projeto

# 

# O site conta com \*\*3 páginas HTML independentes\*\* e integradas entre si:

# 

# 1\. \*\*`index.html` (Início):\*\* Página institucional com a missão e os valores da ONG, banner de destaque (\*Hero Section\*) para atrair potenciais adotantes e uma seção dedicada a depoimentos reais de voluntários e adotantes.

# 2\. \*\*`adote.html` (Galeria de Animais):\*\* Interface em formato de catálogo visual expondo os animais prontos para adoção, contendo fotos, nomes, fichas com idade/porte e botões intuitivos de chamada para ação (\*Call-to-Action\*).

# 3\. \*\*`contato.html` (Contato e Apoio):\*\* Contém um formulário estruturado e validado para captar o interesse de adotantes ou novos voluntários, além de uma seção informativa explicando alternativas de doação e apadrinhamento.

# \## 🛠️ Como Executar o Projeto Localmente

# 

# 1\. Realize o clone deste repositório ou baixe o arquivo `.zip`.

# 2\. Abra a pasta do projeto no editor de código de sua preferência (recomendado: \*\*Visual Studio Code\*\*).

# 3\. Instale a extensão \*\*Live Server\*\* no VS Code.

# 4\. Abra o arquivo `index.html`, clique com o botão direito e selecione \*\*"Open with Live Server"\*\*.

# 5\. O site será executado automaticamente no seu navegador padrão através de um servidor local.

# \## 📊 Critérios de IHM Atendidos

# 

# O design da interface seguiu princípios fundamentais de \*\*Interação Homem-Máquina (IHM)\*\*:

# \- \*\*Consistência:\*\* Menu e rodapé idênticos em todas as telas, facilitando a memorização espacial e de fluxo.

# \- \*\*Acessibilidade de Cores:\*\* Paleta voltada para tons de coral quente, branco e cinzas suaves para inspirar empatia e conforto visual.

# \- \*\*Feedback Visual:\*\* Efeitos dinâmicos de alteração de cor (\*hover\*) aplicados em todos os links de menu e botões clicáveis.

# \- \*\*Escaneabilidade:\*\* Uso de tipografia limpa (sans-serif) e contrastes acentuados em títulos e elementos cruciais textuais.
